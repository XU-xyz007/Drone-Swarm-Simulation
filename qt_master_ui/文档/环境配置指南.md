# 环境配置指南

> 适用：所有组员 | 更新：2026-09-01

---

## 一、前置条件

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| Visual Studio | 2022 | 需安装"使用 C++ 的桌面开发"工作负载，自带 CMake |
| Qt | 6.5.3（MSVC 2019 64-bit） | 通过 Qt Online Installer 安装 |
| Git | 任意版本 | 用于拉取代码 |

---

## 二、安装 Qt6

1. 下载 [Qt Online Installer]
2. 安装时勾选组件：**Qt 6.5.3 → MSVC 2019 64-bit**
3. 记住安装路径，例如 `C:\Qt\6.5.3\msvc2019_64`

---

## 三、配置个人 Qt 路径

你只需要做**一次**：在项目根目录创建 `CMakeUserPresets.json`，写入你的 Qt 路径。

**文件位置：** `qtdemo\CMakeUserPresets.json`

**文件内容：**（把路径改成你自己的）
```json
{
  "version": 3,
  "configurePresets": [
    {
      "name": "x64-debug-local",
      "displayName": "x64 Debug (本地)",
      "inherits": "x64-debug",
      "cacheVariables": {
        "CMAKE_PREFIX_PATH": "C:/Qt/6.5.3/msvc2019_64"
      }
    }
  ]
}
```

路径示例：
- 标准安装：`C:/Qt/6.5.3/msvc2019_64`
- D 盘：`D:/Qt/6.5.3/msvc2019_64`
- 自定义：`E:/Qt_installer/6.5.3/msvc2019_64`

> 注意：路径用**正斜杠** `/`，不要用反斜杠 `\`。末尾不要加 `/bin`。

---

## 四、打开项目

1. 用 Git 拉取代码
2. 按第三步创建好 `CMakeUserPresets.json`
3. 打开 Visual Studio，选择 **"打开本地文件夹"**，选择 `qtdemo` 目录
4. VS 会自动检测 CMake 项目并开始配置
5. 在顶部工具栏的**解决方案配置**下拉框中，选择 **"x64 Debug (本地)"**
6. 等待 CMake 配置完成（输出窗口显示 "CMake 生成完毕"）

---

## 五、构建与运行

- **生成：** 菜单栏 → 生成 → 全部生成（或 `Ctrl+Shift+B`）
- **运行：** 菜单栏 → 调试 → 开始执行（或 `F5`）

---

## 六、常见问题

### Q1：找不到 Qt6，CMake 报错
> 确认第三步的 `CMakeUserPresets.json` 路径正确，且该路径下存在 `lib/Qt6Core.lib`。然后 VS 菜单：**项目 → 删除缓存并重新配置**。

### Q2：提示 "CMakePresets.json 分析配置时出错"
> 可能是文件编码问题（BOM 标记）。在 VS 中打开 `CMakePresets.json`，**文件 → 高级保存选项 → 选择 "Unicode (UTF-8 无签名)"**，保存后重新配置。

### Q3：Qt 头文件找不到（QTimer、QObject 等）
> 删除项目根目录下的 `out/` 文件夹，重新打开项目让 VS 重新配置 CMake。

### Q4：需要选择哪个 preset？
> 选择 **"x64 Debug (本地)"**（带"(本地)"后缀的那个），这是我们通过 `CMakeUserPresets.json` 配置的带 Qt 路径的版本。

## 七、文件说明

| 文件 | 提交 Git | 作用 |
|------|----------|------|
| `CMakeLists.txt` | ✅ | 项目结构定义，不含任何路径 |
| `CMakePresets.json` | ✅ | 共享构建配置（编译器、构建类型） |
| `CMakeUserPresets.json` | ❌ | 个人的 Qt 路径，每人一份 |
| `.gitignore` | ✅ | 忽略 `out/` 和 `CMakeUserPresets.json` |
