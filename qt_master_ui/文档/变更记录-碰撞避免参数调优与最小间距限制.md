# 变更记录：碰撞避免参数调优 & 最小编队间距限制

日期：2026-09-15

---

## 一、问题描述

合并 `feat/autonomous-rearrangement`（PR #15）后，无人机**无法正确到达指定编队位置**，表现为：
- 无人机飞向目标槽位时被反复推开
- 在槽位附近来回振荡，无法进入 HOVER 悬停状态
- 编队收敛时间极长或不收敛

---

## 二、根因分析

### 2.1 V2 碰撞避免系统被激活

**合并前的旧代码**（`SwarmControlCModule::RunLoop`）使用 `MockBModuleCollisionAvoidance`，该函数**直接将意图速度原样返回，不做任何避让**：

```cpp
// 旧代码（合并前）
B_to_C_Response SwarmControlCModule::MockBModuleCollisionAvoidance(...) {
    B_to_C_Response resp;
    resp.is_modified = false;
    resp.safe_vx = req.intent_vx;   // 直接通过，无碰撞避免
    resp.safe_vy = req.intent_vy;
    return resp;
}
```

**合并后的新代码**改用真实 V2 碰撞避免算法 `SwarmAvoidance::ComputeSafeVelocity`，无人机的行为从"直飞目标"变为"带碰撞避免飞行"。

### 2.2 参数与编队间距严重不匹配

合并后的碰撞避免参数与 UI 默认编队间距（5.0m）存在三重冲突：

| 参数 | 合并后值 | 编队间距 | 冲突说明 |
|------|----------|----------|----------|
| `safe_distance` | 5.0m | 5.0m | 安全距离**等于**编队间距，无人机无法靠近槽位到安全距离内 |
| `warning_distance` | 20.0m | 5.0m | 预警距离**4倍**于编队间距，相邻无人机永久处于预警态 |
| `avoidance_gain` | 2.0 | — | 回避力度过大，轻微接近即产生强力推开 |

**逻辑链条**：
```
safe_distance = 5m = 编队间距
    → DynamicWarningDistance 返回 ≥20m（至少取 warning_distance）
    → 所有相邻无人机间距 ≤5m < 20m，始终触发碰撞预警
    → avoidance_gain = 2.0 产生强力修正速度
    → 无人机飞向目标 → 被推开 → 再飞向目标 → 循环
    → 永远无法到达并稳定在槽位
```

## 三、代码修改

### 修改 1：碰撞避免参数调优

**文件**：`Drone/SwarmControlCModule.cpp`

| 参数 | 改前 | 改后 | 理由 |
|------|------|------|------|
| `safe_distance` | 5.0 | **2.0** | 必须小于编队间距(5m)，留出 3m 安全余量 |
| `warning_distance` | 20.0 | **5.0** | 与编队间距匹配，仅在真正接近时才预警 |
| `avoidance_gain` | 2.0 | **0.5** | 让无人机平滑接近目标，而非被强力推开 |

```cpp
// 改前
b_req.config.safe_distance = 5.0;
b_req.config.warning_distance = 20.0;
b_req.config.avoidance_gain = 2.0;

// 改后
b_req.config.safe_distance = 2.0;
b_req.config.warning_distance = 5.0;
b_req.config.avoidance_gain = 0.5;
```

> 💡 这三个参数是调优旋钮。如果编队间距调得更小（如 3m），应同步降低 `safe_distance`（如 1.0m）和 `warning_distance`（如 3.0m）。

### 修改 2：删除 DroneApp.cpp 重复赋值行

**文件**：`Drone/DroneApp.cpp`

合并时产生了一行重复代码，`cur_x_ = c_output.x;` 出现了两次。已删除多余的重复行及对应注释。

### 修改 3：UI 最小编队间距限制

**文件**：`qt_master_ui/QtDemo/MainWindow.cpp`

```cpp
// 改前
m_spinSpacing->setRange(0.5, 100.0);

// 改后
m_spinSpacing->setRange(3.0, 100.0);
m_spinSpacing->setToolTip(QString::fromUtf8("最小间距 3.0m，低于此值可能与碰撞避免安全距离冲突"));
```

**设计依据**：
- `safe_distance = 2.0m` 是两架无人机之间的最小安全距离
- 编队间距必须 `≥ safe_distance + 一定余量`
- 取 `3.0m` 作为下限（safe_distance + 50% 缓冲），防止用户误设为 0.5m
- 同时添加 tooltip 提示，让用户了解限制原因

## 四、参数设计原则

碰撞避免参数与编队间距应满足以下关系，供后续调参参考：

```
safe_distance      ≤  编队间距 - 缓冲(≥1m)
warning_distance   ≤  编队间距 × 1.5
avoidance_gain     ∈  [0.3, 1.0]，间距越小取值越低
```

| 编队间距 | 推荐 safe_distance | 推荐 warning_distance | 推荐 avoidance_gain |
|----------|-------------------|----------------------|---------------------|
| 3.0m（UI 最小值） | 1.0 ~ 1.5 | 3.0 ~ 4.5 | 0.3 ~ 0.5 |
| 5.0m（默认值） | 2.0 | 5.0 | 0.5 |
| 10.0m | 3.0 ~ 4.0 | 8.0 ~ 12.0 | 0.5 ~ 0.8 |
