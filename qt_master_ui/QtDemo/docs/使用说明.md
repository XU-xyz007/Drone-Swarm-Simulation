## 二、参数面板说明

| 参数 | 控件 | 含义 | 默认值 |
|------|------|------|--------|
| **N** | 数字框 | 同时控制的无人机数量（1~200） | 8 |
| **队形** | 下拉框 | 选择要切换的队形类型 | 方阵 |
| **中心 X** | 数字框 | 队形中心的 X 坐标（米） | 0.0 |
| **中心 Y** | 数字框 | 队形中心的 Y 坐标（米） | 0.0 |
| **间距** | 数字框 | 无人机之间的间距（米） | 5.0 |
| **测试模式** | 复选框 | 勾选后使用确定性队形数据 | 不勾选 |

### 队形类型

| 选项 | 含义 |
|------|------|
| 0 - 方阵 | 无人机排列成正方形/矩形网格 |
| 1 - 一字 | 无人机水平排成一行 |
| 2 - 三角 | 无人机排列成等腰三角形 |
| 3 - 圆形 | 无人机等距分布在圆周上 |
| 文字队形 | 自定义文字队形（需 B 配合实现） |

## 三、按钮说明

### 3.1 起飞按钮

| 项目 | 说明 |
|------|------|
| **作用** | 向所有无人机发送"起飞"命令 |
| **效果** | 无人机从灰色（待命）变为琥珀色（起飞中），最终变为绿色（巡航） |
| **使用时机** | 程序刚启动后，第一次操作应该点起飞 |
| **对应命令** | `DroneCmd{ cmd_type: CMD_TAKEOFF }` |

### 3.2 切换队形按钮

| 项目 | 说明 |
|------|------|
| **作用** | 向所有无人机发送"变队形"命令 |
| **效果** | 无人机从当前位置飞向新队形的目标位置 |
| **使用时机** | 起飞后，任何时候都可以切换队形 |
| **对应命令** | `DroneCmd{ cmd_type: CMD_FORMATION, formation_id: 0~3, ... }` |

### 3.3 降落按钮

| 项目 | 说明 |
|------|------|
| **作用** | 向所有无人机发送"降落"命令 |
| **效果** | 无人机从绿色（巡航）变为蓝色（降落中），最终变为紫色（已降落） |
| **使用时机** | 任务结束，准备关闭程序前 |
| **对应命令** | `DroneCmd{ cmd_type: CMD_LAND }` |

### 3.4 急停按钮

| 项目 | 说明 |
|------|------|
| **作用** | 向所有无人机发送"紧急停止"命令 |
| **效果** | 所有无人机立即停止当前动作，悬停在空中 |
| **使用时机** | 出现异常情况，需要立即停止所有无人机 |
| **对应命令** | `DroneCmd{ cmd_type: CMD_EMERGENCY }` |

## 四、无人机颜色含义

| 颜色 | 状态 | 含义 |
|------|------|------|
| 绿色 | 待命 | 已到达目标位置，一切正常 |
| 琥珀色 | 起飞中 | 正在从地面起飞 |
| 黄色 | 移动中 | 正在飞向目标位置 |
| 蓝色 | 降落中 | 正在降落 |
| 紫色 | 已降落 | 已经降落在地面 |
| 红色 | 故障 | 无人机出现故障 |
| 灰色 | 失联 | 与无人机失去通信 |

## 五、典型操作流程

### 标准演示流程

```
步骤 1：设置参数
  → 调整 N（无人机数量）为 8
  → 选择队形为 "0 - 方阵"
  → 保持中心 (0, 0)、间距 5.0

步骤 2：点击 [起飞]
  → 状态栏显示 "已发送起飞命令"
  → 观察画布：无人机变为绿色

步骤 3：点击 [切换队形]
  → 无人机飞向方阵目标位置
  → 状态栏实时显示进度：1/8 → 3/8 → 8/8
  → 完成后状态栏变绿："队形完成！"

步骤 4：切换其他队形
  → 选择 "1 - 一字"，点击 [切换队形]
  → 无人机飞向一字排列目标
  → 选择 "3 - 圆形"，点击 [切换队形]
  → 无人机飞向圆形排列目标

步骤 5：点击 [降落]
  → 状态栏显示 "已发送降落命令"
  → 无人机降落
```

### 测试模式流程

```
步骤 1：勾选 "测试模式（确定性队形）"
  → 状态栏显示 "测试模式：确定性队形"
  → 无人机从随机初始位置开始

步骤 2：点击 [切换队形]
  → 无人机以 3m/100ms 速度飞向目标
  → 终端输出每架无人机到达的日志
  → 全部到达后状态栏变绿

步骤 3：切换队形类型
  → 选择不同队形
  → 点击 [切换队形]
  → 观察不同队形排列效果
```

## 六、测试模式 vs 随机模式

| 项目 | 随机模式（不勾选） | 测试模式（勾选） |
|------|-------------------|-----------------|
| 数据来源 | FakeStateReceiver | TestStateReceiver |
| 运动方式 | 随机游走，无目标 | 确定性飞向目标 |
| 队形验证 | 无法验证（随机） | 可验证 4 种队形 |
| 完成判定 | 随机时间触发 | 全部到达后触发 |
| 适用场景 | 测试渲染性能 | 验证队形逻辑 |

## 七、常见问题

### Q1：为什么所有无人机都堆在同一个位置？
- 随机模式：初始都在 (0,0)，点击起飞后会随机游走散开
- 测试模式：初始分散在 ±20m 范围内，点击队形后会飞向目标

### Q2：点了切换队形但没有变化？
- 确保先点了"起飞"
- 检查是否勾选了"文字队形"但没输入文字

### Q3：如何放大/缩小画布？
- 鼠标滚轮：缩放
- 鼠标拖拽：平移画布

### Q4：状态栏一直显示"队形进行中"？
- 随机模式下，无人机需要足够时间随机游走
- 测试模式下，无人机正在飞向目标（需要几秒）

### Q5：改 N 的数量后有什么影响？
- 下次点击按钮时使用新数量
- 画布上会显示对应数量的无人机
- 队形会自动调整排列方式
