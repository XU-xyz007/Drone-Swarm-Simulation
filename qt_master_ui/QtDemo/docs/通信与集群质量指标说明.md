# 通信与集群质量指标说明

本页说明主控端右侧“通信性能”和“集群质量分析”面板中的指标含义、计算方式与使用边界。所有指标均以**主控端实际接收到的 `DroneState` 状态**为数据源。

## 1. 通信性能

| 指标 | 含义与计算方式 | 如何解读 |
|---|---|---|
| 状态消息 | 最近 1 秒内主控 `StateReader` 实际收到的 `DroneState` 条目数，单位为条/秒。 | 无人机运动时通常约 10 Hz/架；悬停时通常约 1 Hz/架。因此数值会随运动状态变化。 |
| 业务吞吐 | 最近 1 秒内已接收状态的 CDR 业务载荷估算值，单位为 kbit/s。计算为“状态消息数 × 单条业务载荷字节数 × 8 ÷ 1000”。 | 不包含 DDS/UDP/IP 协议头、发现流量和重传等网络开销；用于比较本系统业务数据量。 |
| 序列缺失 | 按同一 `drone_id` 的 `seq_num` 递增关系推断的缺失条目数。 | 0 表示在当前一秒窗口没有发现序号跳跃；大于 0 表示中间可能漏收状态。 |
| 乱序样本 | 当前一秒窗口内 `seq_num` 小于或等于该机已记录最大序号的样本数。 | 可能是乱序到达，也可能是重复样本；0 表示当前窗口未观察到。 |
| 吞吐趋势 | 最近 45 个一秒窗口的业务吞吐曲线。 | 飞行阶段曲线升高、全部悬停后回落是正常现象，反映动态发布频率高于静态发布频率。 |

## 2. 集群质量分析

每次点击“起飞”或“切换队形”时，主控会调用 B 模块的 `GenerateSlots` 生成本轮目标槽位，并按当前约定保存：

```text
drone_id 1..N  ↔  B 算法 slot index 0..N-1
```

### 当前最小机间距

主控对缓存中任意两架无人机的实际坐标计算欧氏距离，显示其中最小值：

```text
min distance = min( sqrt((xi-xj)^2 + (yi-yj)^2) )
```

这是监测值，不会触发或替代 B/C 模块的避障逻辑。队形切换过程中，临时最小间距可能小于最终设定间距；到达稳定队形后应接近设置的“间距”。

### 同步到达误差

当某架无人机首次满足“实际位置到自身目标槽位的距离不超过到达阈值”时，主控记录该条状态到达主控的本地时间。全部无人机达到条件后，显示最早与最晚记录时间之差：

```text
同步到达误差 = max(各机首次到达时间) - min(各机首次到达时间)
```

在尚未全部到达时，界面显示“到达 x/N”。该指标包含不同初始距离、飞行速度和状态消息到达时刻的综合影响，不等同于网络单向时延。

### 队形收敛残差

队形收敛残差表示“无人机当前实际位置离它自己的目标槽位还有多远”。界面显示所有已匹配无人机的**平均**欧氏距离：

```text
平均收敛残差 = (Σ sqrt((xi-targetXi)^2 + (yi-targetYi)^2)) / N
```

- 数值持续下降：队形正在向目标收敛。
- 数值接近 C 模块的到达死区：C 已停止向目标靠近；该值未必是 `0.00 m`。
- 数值长期不下降：需要检查命令是否被执行、`drone_id` 与槽位索引映射是否一致，以及 Controller 与 Drone 是否由同一版本代码构建。

当前 V2 C 模块的 `deadband_radius` 为 `0.10 m`：实际位置到目标槽位的距离不超过 10 cm 时，C 会停止并悬停，而不会再强制把坐标贴到目标点。因此，稳定后的平均收敛残差常显示为约 `0.10 m`（保留两位小数后的平均值）；它不是主控写死的显示下限，也不表示 B 的槽位计算错误。

若项目希望最终显示 `0.00 m`，需要由 C 修改到达策略为“进入死区后将位置钳制到目标坐标”。若项目更强调真实动力学仿真，则应保留死区，并将 `0.10 m` 作为当前 C 端控制精度的解释依据。

## 3. 阈值说明

质量面板不再展示阈值提示文字，以避免把 UI 的统计条件误解为 B/C 的避障控制参数。当前主控的“首次到达”统计阈值为 `0.10 m`，已与 C 模块的到达死区对齐；该数值用于同步到达误差统计，不参与避障决策。

“当前最小机间距”低于 `1.50 m` 时仍会以告警色显示，但不会下发避障命令，也不参与 B/C 的动力学或避障计算。该展示告警值与 B/C 的最终控制约束仍应由联调规范统一确认，后续宜提取为共享配置项。

## 4. 使用建议

1. 每次修改 N、中心、间距或队形后，必须通过“起飞”或“切换队形”发出新命令，主控才会刷新本轮目标槽位和到达记录。
2. 测量最终残差前，先等待所有无人机静止并完成一轮静态状态上报。
3. 比较不同规模或队形时，同时记录状态消息、业务吞吐、同步到达误差、平均收敛残差和最小机间距。
4. 这些指标服务于仿真观测与误差分析；不应直接作为真实飞行安全认证指标。
