## 一、按钮→命令映射

A 的主控端有 4 个按钮，每个按钮按下后构造一条 `DroneCmd` 消息，通过 D 的 DDS 封装库发送到 `CommandChannel`。

### 1.1 起飞按钮

| 字段 | 填充值 | 来源 |
|------|--------|------|
| `cmd_id` | 本地计数器自增 | `m_cmdSender->getLastCmdId() + 1` |
| `cmd_type` | `CMD_TAKEOFF (0)` | 固定 |
| `formation_id` | `0` | 固定（起飞不涉及队形） |
| `formation_text` | `""` | 固定 |
| `target_x` | `0.0` | 固定 |
| `target_y` | `0.0` | 固定 |
| `spacing` | `5.0` | 固定 |
| `expected_count` | `N` | UI 参数面板 `m_spinN->value()` |

### 1.2 切换队形按钮

| 字段 | 填充值 | 来源 |
|------|--------|------|
| `cmd_id` | 本地计数器自增 | `m_cmdSender->getLastCmdId() + 1` |
| `cmd_type` | `CMD_FORMATION (1)` | 固定 |
| `formation_id` | `0`~`3` 或 `0` | 下拉框索引（文字队形时填 0） |
| `formation_text` | `""` 或用户输入 | 文字队形时取 `m_editFormationText->text()` |
| `target_x` | 用户输入值 | `m_spinCenterX->value()` |
| `target_y` | 用户输入值 | `m_spinCenterY->value()` |
| `spacing` | 用户输入值 | `m_spinSpacing->value()` |
| `expected_count` | `N` | `m_spinN->value()` |

> 发送后立即调用 `m_formationChecker->setExpectedCount(N)` 和 `setLatestCmdId(cmd.cmd_id)`，启动队形完成判定。

## 二、状态→画面刷新

### 2.1 数据流

```
DDS StateChannel (10Hz)
    ↓
IStateReceiver::setOnStateReceived(callback)
    ↓
DroneStateCache::updateState(state)        // 写入缓存
    ↓
MainWindow::onRenderTick() (50ms)           // 渲染定时器
    ↓
updateDroneDisplay()
    ├── 从缓存取所有 DroneState
    ├── 创建/更新 DroneItem（QGraphicsEllipseItem）
    │   ├── setPos(state.x, state.y)       // 增量重绘：QGraphicsScene 只刷新变化区域
    │   └── setBrush(colorForStatus(state.status))  // 颜色随状态变
    └── 删除不再活跃的 DroneItem
```

### 2.2 颜色映射表

| 状态枚举 | 含义 | 颜色 | RGB |
|----------|------|------|-----|
| `ST_IDLE (0)` | 待命（已到位） | 绿色 | `(76, 175, 80)` |
| `ST_TAKEOFF (1)` | 起飞中 | 琥珀色 | `(255, 193, 7)` |
| `ST_CRUISE (2)` | 移动中 | 黄色 | `(255, 235, 59)` |
| `ST_LANDING (3)` | 降落中 | 蓝色 | `(33, 150, 243)` |
| `ST_LANDED (4)` | 已降落 | 紫色 | `(156, 39, 176)` |
| `ST_FAULT (5)` | 故障 | 红色 | `(244, 67, 54)` |
| `ST_LOST (6)` | 失联 | 灰色 | `(128, 128, 128)` |

> 实现位置：`render/ColorConfig.h` → `colorForStatus()`

### 2.3 坐标映射

- 坐标系：米制，与 IDL 统一
- 无人机坐标 `(x, y)` 直接映射到 QGraphicsScene 坐标
- 首次渲染时自动 `fitInView()` 适配视野
- 之后用户可滚轮缩放、拖拽平移
- 场景最小范围 400×400 米

## 三、"队形完成"判定

### 3.1 判定逻辑

```
发送队形命令时：
  1. cmd_id = 自增
  2. FormationChecker.setExpectedCount(N)
  3. FormationChecker.setLatestCmdId(cmd_id)
  4. m_formationCompleted = false  ← 重置标记

每收到一个 DroneState：
  1. FormationChecker.updateDroneCmdId(drone_id, current_cmd_id)

每 200ms 检测：
  1. 遍历所有已记录的 drone_id
  2. 检查是否每个 drone 的 current_cmd_id == latestCmdId
  3. 且已记录数量 >= expectedCount
  4. 全部满足 → isFormationComplete() = true
```

### 3.2 判定伪代码

```cpp
bool FormationChecker::isFormationComplete() const {
    if (m_expectedCount == 0) return false;
    if (m_droneCmdIds.size() < m_expectedCount) return false;
    for (const auto& [droneId, cmdId] : m_droneCmdIds) {
        if (cmdId != m_latestCmdId) return false;
    }
    return true;
}
```

### 3.3 状态栏反馈

| 阶段 | 状态栏显示 | 样式 |
|------|-----------|------|
| 刚发送命令 | `已发送队形命令 (方阵)，进度: 0/8` | 默认 |
| 进行中 | `队形进行中，进度: 3/8` | 默认 |
| 全部完成 | `队形完成！` | 绿色背景 + 白色粗体 |

## 四、增量重绘机制

### 4.1 原理

基于 Qt QGraphicsView 框架的天然增量重绘：

- 每个无人机是一个独立的 `QGraphicsEllipseItem`
- 调用 `item->setPos(x, y)` 时，QGraphicsScene 自动计算旧区域和新区域的脏矩形
- 只重绘变化区域，不动的不画
- 不清屏，不闪烁

### 4.2 实现

```cpp
// DroneItem::updateFromState() — 每次渲染 tick 调用
void DroneItem::updateFromState(const DroneState& state) {
    setPos(state.x, state.y);           // QGraphicsScene 自动增量重绘
    setBrush(colorForStatus(state.status));  // 仅颜色变化时重绘
}

// MainWindow::updateDroneDisplay() — 50ms 定时器
void MainWindow::updateDroneDisplay() {
    auto states = m_stateCache->getAllStates();
    for (const auto& state : states) {
        auto& item = m_droneItems[state.drone_id];  // 不存在则创建
        item->updateFromState(state);                // 增量更新
    }
    // 删除不再活跃的 item
}
```

### 4.3 性能指标

| 指标 | 值 |
|------|-----|
| 渲染频率 | 20Hz（50ms） |
| 状态接收频率 | 10Hz（100ms） |
| 支持无人机数 | 1~200 |
| 单点渲染开销 | `setPos()` + `setBrush()`，O(1) |
| 每帧总开销 | O(N)，N=在线无人机数 |

## 五、状态栏/提示规则

### 5.1 常规状态

| 操作 | 状态栏文字 | 持续时间 |
|------|-----------|----------|
| 初始/就绪 | `就绪` | 持续 |
| 点击起飞 | `已发送起飞命令` | 2 秒后恢复 |
| 点击降落 | `已发送降落命令` | 2 秒后恢复 |
| 点击急停 | `已发送急停命令` | 2 秒后恢复 |

### 5.2 队形模式

| 阶段 | 状态栏文字 |
|------|-----------|
| 发送队形命令 | `已发送队形命令 (XXX)，进度: 0/N` |
