# Chinese Hershey font asset

`Heiti.hf.txt` is the pre-generated single-line Heiti font from
[LingDong-/chinese-hershey-font](https://github.com/LingDong-/chinese-hershey-font).
It contains 20,975 basic CJK ideographs and is used only as stroke-coordinate
data by the formation algorithm.
